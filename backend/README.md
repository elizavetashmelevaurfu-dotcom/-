## Как запустить проект (Пошагово)

Шаг 1. Установите Docker
Убедитесь, что у вас запущен Docker Desktop.

Шаг 2. Клонируйте репозиторий

Шаг 3. Запустите Backend
Выполните следующую команду в корневой папке проекта (там, где лежит файл compose.yaml):

docker compose up --build
